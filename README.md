# 🛰️ Middle East OSINT Radar | رادار دیده‌بان خاورمیانه

داشبورد جامع رصد زنده و مانیتورینگ اطلاعات مکانی، نظامی و ژئوپلیتیک رویدادهای خاورمیانه (ایران، اراضی اشغالی، لبنان، یمن و دریای سرخ، سوریه و عراق) با یکپارچه‌سازی تله‌متری و رویدادهای زنده **Iran Monitor**.

An advanced, real-time Open-Source Intelligence (OSINT) and geospatial tracking dashboard designed for situational awareness, tactical monitoring, air defense tracking, and conflict observation across the Middle East.

---

## 🌟 قابلیت‌ها و ماژول‌های سامانه (Key Features)

### ۱. تله‌متری نبض بحران (Iran Monitor Geopolitical Pulse)
* **📰 حجم اخبار جنگ (News Index):** پایش حجم انتشار اخبار مرتبط با تنش‌های منطقه با تفکیک سنتیمنت بحرانی.
* **🐦 ترافیک توییتر / X:** رصد شدت تبادل نظر پیرامون کلیدواژه‌های بحران (#Iran, #Israel, #Hormuz).
* **🌐 پایش پایداری اینترنت ایران:** تله‌متری زنده آپ‌تایم شبکه با تفکیک ترافیک شبکه ملی و ترانزیت بین‌الملل بر پایه Cloudflare / IODA.
* **🛢️ فشار ژئوپلیتیک نفت و انرژی:** قیمت لحظه‌ای برنت و WTI همراه با پرمیوم ریسک تشدید درگیری نظامی.

### ۲. استخراج و فید زنده رویدادهای میدانی (Live Intelligence Feed)
* **استخراج ۹۸ رویداد میدانی زنده:** اتصال به API رسمی دیده‌بان بحران Iran Monitor و پالایش رویدادهای ۷ روز اخیر.
* **تفکیک دسته‌بندی‌های تاکتیکی:** موشکی و پهپادی، پدافند هوایی، درگیری‌های میدانی، عملیات دریایی و نفت، دیپلماسی و تحریم، هشدارهای قرمز، و سایبری.
* **لینک مستقیم به منبع رسمی (🔗 منبع):** امکان مراجعه مستقیم به پست تلگرامی یا گزارش اصلی خبرگزاری (تسنیم، رویترز، بلومبرگ، ایسنا، شرق، المسیره و...).
* **ضریب اهمیت بحران (Impact Score):** ارزیابی ریسک هر خبر از ۱ تا ۵ به همراه مختصات مکانی دقیق روی نقشه.

### ۳. بولتن راهبردی ارزیابی ریسک (AI Daily Crisis Briefing)
* **نشانگر سطح آماده‌باش DEFCON 2:** تحلیل سناریوهای تهاجم و آرایش نیروها.
* **محورهای چهارگانه اقدام تاکتیکی:** پدافند هوایی، گشت‌های هوایی، امنیت دریانوردی، و پایش زیرساخت‌های حیاتی.

### ۴. پخش زنده شبکه‌های خبری ماهواره‌ای (Live TV Broadcast)
* سوئیچ شناور میان پخش زنده الجزیره انگلیسی (Al Jazeera)، رویترز / اسکای نیوز (Sky News Wire) و فرانس ۲۴ (France 24).

### ۵. نقشه تاکتیکال و ابزارهای تحلیلی (Tactical GIS & Controls)
* **چتر پدافند هوایی و بردارهای تهاجم:** نمایش شعاع پوشش راداری سامانه‌های باور-۳۷۳، سوم خرداد، پاتریوت، گنبد آهنین، پیکان و فلاخن داوود.
* **ناوگان دریایی (AIS):** رصد نفتکش‌ها و شناورهای تجاری در تنگه هرمز، جزیره خارگ و باب‌المندب.
* **خط‌کش و ماشین‌حساب بالستیک:** محاسبه مسافت، زمان پرواز موشک‌های بالستیک/کروز و پهپادهای انتحاری.
* **کارت گرافیکی خبر:** خروجی عکس تمیز با فونت وزیر و رزولوشن بالا مناسب انتشار در توییتر و تلگرام.

### ۶. بهینه‌سازی ۱۰۰٪ برای موبایل (Mobile App-Like Experience)
* داک ناوبری شناور زیرین با سوئیچ نرم میان «🗺️ نقشه زنده» و «📰 اخبار و فید».
* شبکه‌بندی متقارن ۲×۲ کارت‌های نبض برای نمایشگرهای لمسی.
* نوار ابزار اسکرولی با دکمه‌های استاندارد لمسی (Touch Target 44px+).

## 🚀 نحوه راه‌اندازی (Quick Start)

### روش ۱: استفاده از سرور پایتون (توصیه‌شده)

```bash
# اجرای بک‌اند همگام‌سازی و API
python3 backend/osint_server.py
```
سپس فایل `index.html` را در مرورگر باز کنید یا از طریق وب‌سرور (Nginx / Caddy) میزبانی نمایید.

### اندپوینت‌های فعال سرور:
* `GET /events`: دریافت لیست رویدادهای کش‌شده با متادیتای نظامی.
* `GET /pulse`: داده‌های تله‌متری نبض بحران، بولتن روزانه و کانال‌های زنده.
* `GET /live_wire`: نوار زیرنویس خبرهای فوری.
* `GET /sync_iranmonitor`: فراخوانی دستی همگام‌سازی با شبکه Iran Monitor.
